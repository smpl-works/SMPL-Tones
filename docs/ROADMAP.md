# SMPL Tones roadmap

All application milestones below are **planned/open**. Publishing this dossier does not complete a model conversion, application build, benchmark or installer. Each step is tracked as an issue with deliverables, tests and a completion gate.

See the [development plan](DEVELOPMENT_PLAN.md) for the complete architecture and [machine-readable definitions](evidence/roadmap.json) for every milestone.

| Step | Milestone | Dependencies | Tracking |
|---|---|---|---|
| 01 | Freeze provenance, licensing and release asset policy | None | [#1](https://github.com/smpl-works/SMPL-Tones/issues/1) |
| 02 | Prove native YourMT3+ inference feasibility | [#1](https://github.com/smpl-works/SMPL-Tones/issues/1) | [#2](https://github.com/smpl-works/SMPL-Tones/issues/2) |
