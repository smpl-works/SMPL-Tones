# SMPL Tones roadmap

All application milestones below are **planned/open**. Publishing this dossier does not complete a model conversion, application build, benchmark or installer. Each step is tracked as an issue with deliverables, tests and a completion gate.

See the [development plan](DEVELOPMENT_PLAN.md) for the complete architecture and [machine-readable definitions](evidence/roadmap.json) for every milestone.

| Step | Milestone | Dependencies | Tracking |
|---|---|---|---|
| 01 | Freeze provenance, licensing and release asset policy | None | Pending publication |
| 02 | Prove native YourMT3+ inference feasibility | 1 | Pending publication |
| 03 | Establish the integrated Windows editor and project foundation | 1, 2 | Pending publication |
| 04 | Implement bounded media processing and recoverable jobs | 3 | Pending publication |
| 05 | Integrate versioned replaceable recognition engines | 2, 4 | Pending publication |
| 06 | Add beat tracking and musically valid notation preparation | 5 | Pending publication |
| 07 | Build synchronized correction and non-destructive take review | 6 | Pending publication |
| 08 | Add stem separation and detailed local processing | 5, 7 | Pending publication |
| 09 | Add vocals, lyric drafts, chord analysis and score reductions | 6, 7, 8 | Pending publication |
| 10 | Complete integrated score, audio, GP5 and LilyPond exports | 7, 9 | Pending publication |
| 11 | Profile, optimize and harden reference workflows | 8, 9, 10 | Pending publication |
| 12 | Package and validate the complete offline Windows release | 11 | Pending publication |

No Project board is required for the initial repository. Dependency links and issue URLs are filled during GitHub publication.
